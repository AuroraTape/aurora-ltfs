# Files in this directory

- altfs.conf.example: `altfs.conf` as the build generates it for Linux
- altfs.conf.local.example: `altfs.conf.local` with the directives it can hold
- filedebug_tc_conf.xml: cartridge configuration sample for the `file` tape backend

The configuration files are described in
[docs/user/CONFIGURATION.md](../docs/user/CONFIGURATION.md).
