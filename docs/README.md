# Documentation

The [README](../README.md) covers what Aurora LTFS is, the supported platforms
and drives, installing the packages and a quick start. The man pages, installed
with the commands, are the reference for each command and option.

## Using Aurora LTFS

- [BUILDING.md](BUILDING.md): building from source on Linux, macOS, FreeBSD
  and NetBSD, running the test suites, building the packages
- [conf/README.md](../conf/README.md): the syslog, logrotate and systemd files
  installed with the commands, and a syslog-ng example
- [tests/realdrive/README.md](../tests/realdrive/README.md): checking a real
  tape drive, and what to send when reporting one
